# Obsidian Integration Skill Profile

## Domain
Markdown-based knowledge management and Obsidian-compatible workflows.

## Standards
- **Frontmatter:** Every note must include a YAML frontmatter block with `created`, `updated`, and `tags`.
- **Linking:** Prefer `[[WikiLinks]]` over standard Markdown links for internal references.
- **Structure:** Follow the [P.A.R.A.] or [Zettelkasten] method as specified in project metadata.
