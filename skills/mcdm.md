# MCDM/MCDA Skill Profile

## Domain
Multicriteria Decision Making (MCDM) and Multicriteria Decision Analysis (MCDA).

## Technical Requirements
- **Libraries:** Prefer `NumPy`, `SciPy`, and `Pandas` for matrix calculations.
- **Methods:** Implementation priorities for AHP, TOPSIS, and PROMETHEE.
- **Data Handling:** Ensure all decision matrices are normalized according to [standard practice].
